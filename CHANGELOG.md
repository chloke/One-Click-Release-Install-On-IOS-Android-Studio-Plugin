# Changelog

## 1.0.2

- Added an IDE progress indicator while the iOS app is being built, installed, and launched.

## 1.0.1

- Added an option to remember the selected iOS device for each project.
- Automatically use the remembered device whenever it is available.
- Fall back to the device chooser when the remembered device is unavailable, allowing a new selection to overwrite the preference.

## 1.0.0

- Added a native Android Studio toolbar action for standalone Flutter release installations on iOS.
- Detect and select supported physical iOS devices.
- Locate the Flutter SDK automatically with a manual-path fallback.
- Display Flutter output in the Run tool window and report completion through notifications.
